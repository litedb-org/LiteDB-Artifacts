# Derived reports and provenance

Every file here is explicitly derived from retained local evidence; originals remain separate and unmodified. source-provenance.json supplies source-file SHA-256 without machine-specific directories. hosted-status-derived.json is a frozen observation, not a live status claim. Binary hashes are metadata only; no executable or symbol files are included.

Source commits, environments, reproduction instructions, historical failures and limitations are summarized in the bundle README and the individual reports. Upgrade instructions and original probe source are in ../upgrade-harness. Query measurements are single fresh-process observations, not a production benchmark.
